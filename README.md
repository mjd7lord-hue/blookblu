# blookblu — بک‌اند بلوک

بک‌اند اپ **بلوک** برای شش نقش شخصی: کارگر، متخصص، مهندس، پیمانکار، شرکت ساختمانی و کارفرما.

**فناوری:** Node.js 22 · Express · TypeScript · PostgreSQL (Supabase) · Drizzle ORM · Zod · JWT

## فاز ۱ (همین نسخه)

| بخش | چه کار می‌کند |
|---|---|
| ورود با OTP | ارسال کد ۵ رقمی، محدودیت ارسال و تلاش، توکن دسترسی + refresh چرخشی با تشخیص سرقت |
| ثبت‌نام نقش‌ها | فرم مخصوص هر نقش، دقیقاً مثل اپ؛ خطا برای هر فیلد به فارسی |
| چند نقشی | افزودن نقش دوم، تعویض نقش فعال، حذف نقش |
| پروفایل | شناسنامهٔ کاری با کد (مثل `B-7K31`)، مهارت و تعرفه، روزهای آزاد هفته، حریم خصوصی |
| آگهی و کاوش | سه نوع آگهی (آمادهٔ همکاری / نیاز به نیرو / پرسش تخصصی)، جست‌وجو و فیلتر، مرتب‌سازی بر اساس اعتبار |
| پاسخ به آگهی | اعلام آمادگی، پذیرش/رد، پس گرفتن؛ درخواست‌های ورودی و خروجی |
| اعتبار | امتیاز ۱۰۰ نمره‌ای (همان فرمول اپ)، نظر فقط بعد از همکاری پذیرفته‌شده، قیم (ضامن) |
| ذخیره‌ها | ذخیرهٔ آگهی و پروفایل |
| اعلان‌ها | اعلان درون‌برنامه‌ای با احترام به تنظیمات کاربر |
| ایمنی | گزارش کاربر/آگهی، مسدودسازی دوطرفه |

فهرست کامل مسیرها: [`docs/API.md`](docs/API.md)

## راه‌اندازی روی کامپیوتر

```bash
npm install
cp .env.example .env        # بعد مقادیر را پر کن
npm run db:migrate          # ساخت جدول‌ها در Supabase
npm run db:seed             # (اختیاری) ۴ کاربر و آگهی نمونه
npm run dev                 # http://localhost:3000/api/health
```

### اتصال به Supabase
1. در Supabase: **Project Settings → Database → Connection string → URI** و گزینهٔ **Session pooler** را بردار.
2. در `.env` بگذار: `DATABASE_URL=...` و `DB_SSL=true`.
3. `npm run db:migrate` را بزن.

> نکته: اگر Supabase از ایران یا از سرور لیارا در دسترس نبود، کافی است `DATABASE_URL` را به PostgreSQL لیارا عوض کنی؛ کد هیچ وابستگی دیگری به Supabase ندارد.

### پیامک
در توسعه `SMS_PROVIDER=console` است و کد در لاگ و (با `OTP_DEV_ECHO=true`) در پاسخ API می‌آید.
برای واقعی: `kavenegar` (قالب Verify با نام `KAVENEGAR_TEMPLATE`) یا `melipayamak` (خط خدماتی با `MELIPAYAMAK_BODY_ID`).

## استقرار روی لیارا
1. یک برنامهٔ Node.js با نام `blookblu` بساز.
2. متغیرهای محیطی `.env.example` را در بخش تنظیمات برنامه وارد کن (`NODE_ENV=production`، `OTP_DEV_ECHO=false`).
3. `liara deploy` — دستور `npm start` اول migration را اجرا می‌کند، بعد سرور را.

## تست
```bash
npm test     # ۲۲ تست یکپارچه روی یک دیتابیس PostgreSQL تست
```
دیتابیس تست با `TEST_DATABASE_URL` تعیین می‌شود (پیش‌فرض: `postgresql://blook:blook@localhost:5432/blook_test`). **هرگز آن را به دیتابیس اصلی وصل نکن** — تست‌ها جدول‌ها را پاک می‌کنند.

## ساختار پوشه‌ها
```
src/
  config/env.ts            تنظیمات و بررسی متغیرهای محیطی
  db/                      اسکیما، اتصال، migration، دادهٔ نمونه
  lib/                     ابزارها (خطا، JWT، پیامک، شماره تلفن، ...)
  middlewares/             احراز هویت و مدیریت خطا
  modules/
    auth/                  OTP و توکن
    roles/                 تعریف فرم هر نقش + اعتبارسنجی
    profiles/              حساب من، نقش‌ها، پروفایل عمومی، جست‌وجوی افراد
    ads/                   آگهی، کاوش، پاسخ‌ها
    trust/                 نظرها و قیم
    saved/ notifications/ safety/
drizzle/                   فایل‌های SQL مهاجرت
tests/                     تست‌های یکپارچه
```
